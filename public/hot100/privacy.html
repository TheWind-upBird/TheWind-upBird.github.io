一句话版本：学习进度、代码和笔记默认只保存在你当前的浏览器；SolveShift 当前没有账号服务器，也不把这些内容发送给开发者。

1. 当前会处理哪些数据

  • 学习记录：当前题目、已完成卡片、掌握状态、复习队列和学习设置。
  • 用户内容：编辑器代码和个人笔记。
  • 本地产品事件：课程开始、运行、通过、复习、面试练习等白名单事件；不含代码、笔记和测试输入。
  • 诊断信息：只有你主动打开反馈时才生成预览，包括版本、页面、浏览器、屏幕、网络、状态大小和本次会话错误摘要。

2. 数据保存在哪里

上述内容保存在当前浏览器的本地存储和缓存中。当前版本没有 SolveShift 云端数据库、账号画像、广告 SDK 或远程分析 SDK。更换设备、无痕模式、清理站点数据或浏览器故障可能使本地数据丢失。

3. 何时会连接第三方

首次运行 Python 时，独立 Worker 会从固定版本的 jsDelivr CDN 加载 Pyodide 运行环境。你的学习代码在浏览器内执行，SolveShift 不把代码提交到自己的服务器。点击“打开 GitHub Issue”会打开 GitHub；只有你自行检查并提交后，反馈内容才会发送给 GitHub。

4. 导出、删除和撤回

你可以在工具菜单导出完整 JSON 备份。使用“重置全部进度”可删除主要学习记录，操作前会创建本地快照；也可以在浏览器设置中删除本网站全部站点数据。因为当前没有云端账号，开发者无法从服务器恢复或替你删除本机数据。

5. 数据最小化与安全

产品不请求位置、联系人、相机、麦克风或广告跟踪权限。Python 运行在可终止的独立 Worker 中，单次运行有时间和源代码大小限制；页面使用内容安全策略限制脚本、网络和 Worker 来源。

6. 反馈与安全问题

普通问题可使用产品内反馈入口。请不要在公开 Issue 中粘贴个人信息、私人代码或敏感日志。安全漏洞应使用 GitHub 仓库的私密漏洞报告功能；具体范围见 安全政策。

7. 变更

如果未来加入账号、服务器同步或远程分析，本说明必须在功能启用前更新，并在需要时取得明确同意。当前版本号与发布通道会显示在产品工具菜单中。
