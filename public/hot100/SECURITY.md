# SolveShift 安全政策

## 支持范围

当前支持 `0.4.x-beta` 的最新发布候选。更早的本地副本可能缺少 Python Worker 隔离、超时终止、内容安全策略或数据保护状态，应升级后再复现问题。

## 私密报告安全问题

请优先使用 GitHub 仓库的 **Security → Report a vulnerability** 私密报告入口。不要为未修复漏洞创建公开 Issue，也不要提交真实个人数据、访问令牌、私人代码或其他人的学习记录。

报告应尽量包含：

- 受影响的 SolveShift 版本和浏览器。
- 最小复现步骤与预期/实际结果。
- 影响范围，例如代码执行、数据丢失、越权网络请求或内容注入。
- 不含敏感内容的截图或精简示例。

## 当前安全边界

- 用户 Python 在独立 Web Worker 中运行，单次运行默认 4 秒超时，完成或失败后销毁 Worker。
- 代码和笔记默认仅保存在本机；无 SolveShift 账号服务器或远程数据库。
- 内容安全策略只允许本域资源和固定 jsDelivr Pyodide 来源。
- 发布配置可单独停用 Python、反馈和留存功能，避免必须回滚全部课程内容。
- 本项目不请求相机、麦克风、位置、联系人或广告跟踪权限。

## 不属于漏洞

课程内容错误、浏览器主动清理本地数据、离线时首次无法下载 Pyodide、第三方服务中断属于普通产品问题；可通过产品内反馈报告。
