# SolveShift Web Beta 发布清单

本文定义 SolveShift 当前 Web Beta 的发布边界和最低质量门槛。它是发布操作清单，不替代产品需求或技术架构文档。

## 1. 本次 Beta 的承诺

用户可以在不登录的情况下完成 Hot100 学习路线，使用学习、刷题和面试三种模式，运行 Python 测试，获得复习安排、回归路线和每周学习证据，并把完整学习记录导出到本地文件。

发布版本：`0.4.0-beta.2`。

暂不承诺：账号、云端同步、跨设备自动恢复、多人协作、付费、原生 iOS 客户端或服务器端判题。首次加载 Python 运行环境仍需要联网；之后可使用已缓存的课程页面，但不能保证 Pyodide CDN 资源在所有离线场景都已完整缓存。

## 2. 发布阻断条件

以下任一项成立时不得发布：

- `npm run qa` 未全部通过。
- 99 道可执行 Python 参考实现存在失败。
- 用户代码可能永久阻塞页面，或超时后不能再次运行。
- 全新浏览器无法完成首次设置并进入第一课。
- 导出、导入、快照恢复或重置可能无提示覆盖当前进度。
- 手机宽度出现无法触达的主操作或横向溢出。
- Service Worker 缓存清单漏掉当前版本的必需资源。
- 隐私说明、使用条款或朋友内测任务无法从产品内访问。
- 反馈诊断包含用户代码、笔记、测试输入或唯一用户标识。

## 3. 自动发布门槛

在候选提交上运行：

```bash
npm run release:check
npm run release:evidence
git diff --check
```

预期结果：16 个 Node QA 套件全部通过、99 / 99 Python 参考实现通过、无空白错误；发布证据应准确记录版本、渠道、灰度环、功能开关、缓存版本、提交号和已知限制。GitHub Actions 必须执行相同的门槛并保存证据文件。

## 4. 人工冒烟路径

使用一个从未打开过该域名的浏览器来源，分别验证桌面和约 390px 手机宽度：

1. 首页可读，首次设置可跳过，也可完成起点诊断。
2. “开始我的路线”直接进入第一课；学习、刷题、面试可互相切换。
3. 正确代码连续运行两次，测试、运行历史和本地证据正确累计。
4. `while True` 在约四秒后中止；页面仍可打开工具抽屉，代码原样保留，再次运行可成功。
5. Review 无任务、题库无搜索结果、Interview 无可用题时都有下一步操作。
6. 工具抽屉显示网络、离线缓存、版本、反馈入口和数据保护状态。
7. 导出后得到 `solveshift-progress-YYYYMMDD.json`，外部备份状态立即更新。
8. 刷新和 Service Worker 更新后，当前题、代码、笔记和进度仍在。
9. 键盘焦点可见，Escape 能关闭对话框，运行结果会被辅助技术播报。

## 5. 发布操作

1. 确认候选分支工作树干净，记录提交号和 QA 结果。
2. 检查 `release-config.js`：版本与渠道正确，当前灰度环仍为 `friends`，Python、反馈和留存开关符合本轮范围。
3. 合并到 `main`，在 `main` 上重新执行完整自动门槛。
4. 推送后等待 GitHub Actions 通过，再检查 GitHub Pages 部署状态。
5. 对线上 URL 执行第 4 节的最短路径：首次进入、运行、超时恢复、备份、手机布局。
6. 按 `SolveShift-Launch-Readiness-v1.md` 召开手动 Go / No-Go；未经决定不把灰度环从朋友内测提升到公开 Beta。
7. 记录发布日期、提交号、缓存版本、功能开关、已知限制和回滚提交号。

## 6. 回滚与用户保护

- 发布前保留上一个已验证提交号；线上出现阻断问题时恢复该提交并重新部署。
- Service Worker 每次发布必须提升缓存版本，激活时只清理旧的 `hot100-*` 缓存。
- 回滚不能修改或清空 `hot100-lab-state-v2`、进度快照、外部备份状态等本地记录。
- 如果数据格式发生不兼容变化，先提供兼容读取或迁移；不能用静默重置代替迁移。
- 事故说明应包含影响范围、临时绕过方式和确认修复的版本，不披露用户提交内容。

## 7. Beta 观察指标

当前指标仅保存在用户设备，不进行远程采集：

- 是否进入第一课、开始课程和完成卡片。
- 代码运行、通过、复习和面试练习次数。
- 回归路线开始和每周报告打开。
- 反馈入口打开和诊断复制。

判断产品是否值得继续投入时，优先看朋友实测能否独立完成首次学习、第二天回来、从失败恢复、完成一次复习，以及是否愿意继续使用；不要把页面浏览量当成学习有效性的替代指标。
